# MASTER ARCHITECTURE PROMPT: Immersive Angular PWA Portfolio

## 1. Project Overview & Identity
**Developer Identity:** Piyush Sonawane, Software Engineer (SDE Intern at MCMH) based in Pune, Maharashtra.
**Core Concept:** An Awwwards-tier, Progressive Web App (PWA) portfolio built with Angular 17+ (Standalone Components, Signals). 
**UI/UX Paradigm:** A digital-meets-analog spatial canvas combining minimalist hand-drawn aesthetics, Prezi-style camera navigation, tactile audio feedback, and hardware-accelerated interactive components.

## 2. Visual Art Direction & "The Reveal Rule"
*   **Base Aesthetic:** High-contrast monochrome. Backgrounds are off-white paper tones (`#f8f8f6`), text and UI borders are ink-black (`#111111`). Incorporate subtle halftone/stipple CSS textures for depth.
*   **Typography:** A mix of a clean, geometric sans-serif for UI data (e.g., Inter or Roboto) and a custom handwritten script font for overlay accents and section titles.
*   **The Reveal Rule (Strict Constraint):** The entire application remains grayscale. Color is strictly reserved for user-driven reveals.
    *   *Implementation:* The hero portrait of Piyush defaults to `filter: grayscale(100%) contrast(1.1)`. Only when the user hovers over (or taps) the portrait does it smoothly transition (`0.4s ease-in-out`) to full vibrant color.

## 3. Spatial Navigation & Canvas Layout (Prezi-Style)
*   **Discard Vertical Scrolling:** The application lives on a massive, fixed-position virtual 2D grid.
*   **GSAP Camera Engine:** Use GreenSock (GSAP) combined with Angular to manipulate the `.canvas-container`.
*   **Transitions:** Clicking navigation links (Home, Projects, Skills) triggers a spatial transition. The "camera" (viewport) must zoom out, pan smoothly across the canvas to the specific section coordinates, and zoom back in, simulating a Prezi presentation. Apply slight 3D rotation (`rotateX`, `rotateY` ~2-5 degrees) during the flight for parallax depth.
*   **App Shell:** A fixed UI layer sits above the moving canvas. This includes:
    *   Top Right: A sleek "+ Install App" button bound to the PWA `beforeinstallprompt`.
    *   Bottom: A native-feeling, frosted-glass Tab Bar for mobile devices.
    *   Top Left: A global "Mute Sound" toggle.

## 4. Sensory UI: Tactile Audio & Haptics
*   **Web Audio API:** Load lightweight `.mp3`/`.wav` assets into a singleton Angular `AudioService`.
    *   *Spatial Flights:* A low-frequency, soft paper-sliding or swoosh sound when the GSAP camera moves between sections.
    *   *Interactions:* Muted, satisfying mechanical clicks or pencil-taps when hovering over buttons or expanding project cards.
*   **Haptic Engine:** Utilize `navigator.vibrate()` for mobile users.
    *   Light tap (`navigator.vibrate(10)`) when selecting tabs or filtering the tech stack.
    *   Double tap (`navigator.vibrate([10, 30, 10])`) on successful PWA installation.

## 5. Core Interactive Components

### A. 3D Gyroscope ID Badge (`<app-dev-badge>`)
*   **Purpose:** Replaces the standard "About" text block.
*   **Visual:** A realistic physical corporate ID badge featuring Piyush's photo, barcode, and "SDE Intern · MCMH" designation.
*   **Interaction:** Uses a custom Angular Directive to track mouse coordinates (Desktop) or the `DeviceOrientationEvent` API (Mobile PWA). The card tilts dynamically using `transform: perspective(1000px) rotateX(...) rotateY(...)`. Include a dynamic CSS radial gradient to simulate a specular light glare that moves across the card surface as it tilts.

### B. Periodic Table of Tech (`<app-tech-matrix>`)
*   **Purpose:** Displays technical skills interactively.
*   **Structure:** Elements like `[Js]`, `[Ts]`, `[Re]`, `[Nd]`, `[Ge]` (Gemini API), and `[Dk]` (Docker) arranged in a chemical grid.
*   **Interaction:** Top filter pills (Languages, Frontend, Backend, AI/ML). Clicking a filter uses Angular Signals to update state, dimming out inactive elements (`opacity: 0.25; filter: grayscale(100%)`) and highlighting active ones. Hovering an element reveals a tooltip with production experience details.

### C. Split-Screen Project Deck (`<app-project-deck>`)
*   **Purpose:** Showcases OneMeal, AI Stroke Detection, and OneOps.
*   **Structure:** Horizontal accordion layout. 
    *   *Left Rail:* Vertical index (`01 / OneMeal`, `02 / AI Stroke`, `03 / OneOps`).
    *   *Right Stage:* Expanding view for the selected project, featuring the challenge, pipeline, and live/GitHub links.
*   **Interaction:** Switching projects uses Angular layout animations (enter/leave transitions). Buttons use magnetic spring-physics (pulling slightly toward the cursor on hover).

### D. Bento Metric Grid (`<app-metric-bento>`)
*   **Purpose:** Highlights quantitative achievements (1x Hackathon Winner, 8.43 SGPA, Leadership).
*   **Interaction:** Uses `IntersectionObserver`. When the camera pans to this section, Angular Signals trigger an incrementing number counter animation from `0` to the target value.

## 6. Data Architecture (Strict JSON)
All content must be strictly decoupled from the UI. An injectable `PortfolioService` must fetch and provide this data using Typescript Interfaces.
*   **File:** `assets/data/portfolio.json`
*   **Data Points Required:**
    *   *Hero:* Name, Title, Contact links.
    *   *Projects:* Title, subtitle, description, tech stack array, repo/live URLs.
    *   *Experience:* Company, role, duration, highlight bullets.
    *   *Skills:* Categories and string arrays for the periodic table.

## 7. Technical PWA & Performance Standards
1.  **Architecture:** Angular 17+ with Standalone Components. Strictly use Angular Signals (`signal`, `computed`, `effect`) for state management. No `NgModules` or heavy RxJS `BehaviorSubjects` for static local state.
2.  **Service Worker:** Configure `@angular/service-worker` in `ngsw-config.json` to pre-cache the App Shell, GSAP libraries, and all audio/image assets (Offline-first strategy).
3.  **Install Prompt:** Intercept the `beforeinstallprompt` event in an Angular Service, prevent the default browser behavior, and bind the prompt to the custom UI button.
4.  **Web Manifest:** Must include `theme_color: "#f8f8f6"`, `display: "standalone"`, and a full suite of standard and maskable icons.
5.  **Optimization:** Use WebP formats via `<picture>` tags. Ensure all animations utilize `transform` and `opacity` properties to prevent DOM repaints and guarantee 60fps performance on mobile.
